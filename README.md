# Digital Image Processing

河南大学计算机科学与技术专业课程资料 - 数字图像处理。

## Directory Structure

- `slides/`: 雨课堂ppt.
- `notes/`: 小总结.
- `exams/`: 往年期末考试卷子.
- `project/`: 期末论文复现大项目.
